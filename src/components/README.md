# Components

This directory contains all React components used in the wedding website.

## Structure

- `ui/`: Reusable UI components
- `layout/`: Layout components (header, footer, etc.)
- `invitation/`: Components related to wedding invitation
- `events/`: Components for displaying event details
- `rsvp/`: RSVP form components
- `gallery/`: Photo gallery components
- `auth/`: Authentication-related components
